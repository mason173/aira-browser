# 更新日志

## 3.4.1 (1000465)

2026-09-25

这次更新继续打磨电脑端界面，并把手机上的一些细节收拾干净。

- 电脑端标签页变窄时不再只剩一个省略号；标题会按实际可用的位置留出能看清的字数，实在放不下才隐藏。
- 电脑端标签页的样式面板关闭时不再闪一下。
- 电脑端顶部提示改为卡片宽度，不再挡住整行空白。
- 电脑端在书签、历史、设置等原生页面上点一下页面，地址栏的建议面板就会收起。
- 电脑端工具栏补上翻译网页按钮和地址栏左侧的页面控制按钮；主页和编辑地址时才会显示搜索引擎按钮。
- 实验室的「网页底栏防遮挡」只在手机界面显示；电脑端不再出现这个开关，已经打开过的设置不会丢。
- 社区版在「关于Aira」里新增交流 Telegram 群，点开可在浏览器里打开；Aira 是默认浏览器时会在新标签页里打开。

## 3.4.0 (1000462)

2026-09-25

这次更新把电脑端的元素审查、书签栏和常用弹窗收成一套桌面界面，并修好了新窗口空白页和微博视频接管的问题。

- 电脑端元素审查改为贴在页面右侧，可查看结构、样式、控制台、源代码和网络；悬停即可选中，刷新后面板仍留在原地。
- 审查菜单改为窗口内实心底，不会画出屏幕外。
- 书签、历史、下载、离线页和书架在电脑上共用同一套侧栏和顶栏；离线页按普通标签页打开。
- 右上角菜单悬停可展开历史和书签，并在右侧显示快捷键。
- 书签栏支持右键和长按打开同一套菜单；文件夹逐级展开，网址行使用地球图标。
- 地址栏可用上下键选择建议，回车打开选中项。
- 资源嗅探、应用内代理、脚本详情和「编辑或粘贴源码」在电脑上改为居中对话框；手机仍是底部面板。
- 网页缩放以当前页面打开时的比例为 100%。
- 顶部提示改为卡片宽度，不再挡住整行空白。
- 车机窗口会避开状态栏和底部系统按钮。
- 电脑上用新窗口打开网页时，不再弹出无边框空白页。
- 微博视频接管不再只剩声音、画面冻住。
- 从微信等应用打开的 .user.js 文件会进入安装确认，而不是把路径当网址打开。

## 3.3.2 (1000455)

2026-09-23

这次更新可以自定义下载位置，电脑端的下载设置改为居中对话框，并修好了登录态丢失、标签页预览错位和第三方主页冷启动的问题。

- 下载设置在电脑上改为居中对话框，带标题栏，子页可以在弹窗内返回。
- 下载位置可以改成自己选的文件夹，之后的普通下载会保存到那里；私密下载仍按原来的私密设置处理。
- 下载确认框改用现成的文件类型图标，并可以在确认前更换保存位置。
- 电脑端工具栏菜单重新整理，历史、书签、下载、页面工具和设置从同一处打开。
- 设置列表的图标改为彩色底，和现有图标资源保持一致。
- 居中弹窗改为不透明的主题表面，滚动内容不再透出后面的页面。
- 切到后台或划掉应用前会立刻保存 Cookie，避免刚登录的网站登录态丢失。
- 修复标签页缩回或切到后台后，预览被换成页面顶部的问题。
- 修复第三方主页冷启动时闪白、先显示浅色，以及上拉展开搜索时盖住页面的问题。

## 3.3.1 (1000448)

2026-09-21

这次更新让标签页样式可以三选一，并修好了下载和网页内跳转会打乱标签页状态的问题。

- 外观里的「标签页样式」现在提供三种布局：卡片平铺、横向大卡片、堆叠式，默认卡片平铺，可随时切换。
- 修复横向大卡片布局下进入标签页总览时，当前卡片会先消失再出现的问题。
- 修复中间栏上滑时偶尔先闪出工具面板、又把面板收掉的问题；上滑与「标签页」按钮现在走同一套判断。
- 修复广告等旁路下载把正在浏览的页面回退到旧网址并重新加载的问题，同一次下载提示不再重复回退。
- 修复网页内跳转（锚点、History API、单页应用路由）后重新打开该标签页会回到旧页面的问题。
- 修复在搜索结果页自带的搜索框里改词重搜后，快捷搜索行消失、只能靠返回恢复的问题。
- 修复从书签、历史记录、离线页或用户脚本安装等入口打开的网址，在应用切回前台后被反复重新打开的问题。
- 「工具栏自定义」页面的工具栏预览改为静态绘制，进入页面不再卡顿。

- 标签页概览改为堆叠卡片呈现，并作为默认形态；卡片按层级缩放，一眼看得出前后关系。

- 关闭一个标签页后，整叠卡片仍可继续平移，不会卡住。
- 「工具栏自定义」可选择中间栏上滑打开的面板：工具面板或标签管理页。
- 同步结果对话框改为按「名称 / 状态」列表展示，较长的名称不再被挤压。
- 修复分段标签切换后标题不重绘的问题。
- 社区版的更新提示改为从公开发布 feed 播报。

## 3.2.3 (1000439)

2026-09-19

这次更新把历史记录同步的重活挪到后台、减少同步流量，修好了部分 NAS 上 WebDAV 首次同步失败的问题，并让跨设备互联在电脑端更顺手，同时统一了弹窗与命名。

- 历史记录同步的本地读取和差异计算改到后台线程，同步时界面更跟手；没有变化时直接跳过，删除少量记录也不会再重复上传整个分片。
- 兼容 fnOS 等会在加锁时生成 0 字节文件的 NAS：WebDAV 首次同步不再失败，此前留下的空快照文件也会自动修复。
- 跨设备互联适配电脑端：在电脑界面下改为设置内嵌面板，「互联教程」就地打开，不再跳成整页。
- 电脑端地址栏新增「跨设备标签页」入口，可直接查看并打开其它电脑上正在浏览的网页。
- 修复电脑端在「同步」页面点击「跨设备互联」时被切回「通用」的问题。
- 「互联教程」里的 Chrome、Edge、Firefox 换成官方图标。
- 名称统一为「跨设备互联 / 跨设备标签页 / Aira-sync 扩展 / 私有化部署 / 网页接力」。
- 弹窗按钮统一为上下排列、主操作在上；「清除浏览数据」在手机上改为沉浸式底部面板；电脑端弹窗不再因宽度限制被裁切。
- 底部工具栏手势引导按设备只提示一次，不再重复弹出。
