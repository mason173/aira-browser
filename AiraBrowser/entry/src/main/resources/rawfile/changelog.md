# 更新日志

## 3.4.0 (1000462)

2026-09-25

这次更新把电脑端的元素审查、书签栏和常用弹窗收成一套桌面界面，并修好了新窗口空白页和微博视频接管的问题。

- 电脑端元素审查改为贴在页面右侧，可查看结构、样式、控制台、源代码和网络；悬停即可选中，刷新后面板仍留在原地。
- 审查菜单改为窗口内实心底，不会画出屏幕外。
- 书签、历史、下载、离线页和书架在电脑上共用同一套侧栏和顶栏；离线页按普通标签页打开。
- 右上角菜单悬停可展开历史和书签，并在右侧显示快捷键。
- 书签栏支持右键和长按打开同一套菜单；文件夹逐级展开，网址行使用地球图标。
- 地址栏可用上下键选择建议，回车打开选中项。
- 资源嗅探、应用内代理、脚本详情和「编辑或粘贴源码」在电脑上改为居中对话框；手机仍是底部面板。
- 网页缩放以当前页面打开时的比例为 100%。
- 顶部提示改为卡片宽度，不再挡住整行空白。
- 车机窗口会避开状态栏和底部系统按钮。
- 电脑上用新窗口打开网页时，不再弹出无边框空白页。
- 微博视频接管不再只剩声音、画面冻住。
- 从微信等应用打开的 .user.js 文件会进入安装确认，而不是把路径当网址打开。
