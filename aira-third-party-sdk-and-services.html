Aira第三方SDK、第三方服务及外部数据交互清单

更新日期：2026年5月27日

1. 说明

为保障您的知情权，我们依据 Aira 当前版本实际功能，列明应用中接入的第三方 SDK / Kit、预设第三方服务，以及您主动配置或访问外部服务时可能发生的数据交互。

本清单是 Aira 隐私声明的组成部分。具体个人信息处理规则、权限调用、数据保存和用户权利行使方式，请以 Aira 隐私声明为准。

Aira 是浏览器类应用。您主动访问的网站、安装的用户脚本、导入的规则源、配置的 WebDAV 或翻译接口，可能由对应服务方按照其自身隐私政策处理数据。请您在使用前自行确认对应服务来源可信。

SDK AGC 认证服务 Auth（@hw-agconnect/auth） 华为软件技术有限公司及其关联公司 用于 AGC 用户认证、云服务鉴权、登录状态管理和云数据库访问控制。 AGC 用户标识、登录状态、认证令牌、账号绑定状态及必要的鉴权信息。 用户登录华为账号、使用书签云同步、会员授权、邀请码或云侧能力时。 是 是 以 AppGallery Connect、AGC 认证服务和华为相关隐私规则为准。
Kit Cloud Foundation Kit（@kit.CloudFoundationKit） 华为软件技术有限公司及其关联公司 用于华为 Cloud DB 云数据库能力，支持书签云同步、会员授权、邀请码等云端数据访问。 华为账号标识、书签和文件夹数据、同步元数据、会员授权记录、邀请码和邀请码额度等。 用户开启书签云同步、恢复同步、查询会员状态、兑换邀请码或使用相关云端能力时。 是 是 以华为 Cloud Foundation Kit、AppGallery Connect 和对应云服务说明为准。
Kit 华为应用内支付 IAP Kit（@kit.IAPKit） 华为软件技术有限公司及其关联公司 用于 Aira Pro 订阅购买、恢复购买、查询订阅和打开订阅管理页面。 商品 ID、订阅周期、订单信息、购买结果、支付状态、订阅状态等。 用户点击购买 Aira Pro、恢复购买或管理订阅时。 是 是 以华为应用内支付、华为订阅管理页面和平台规则为准。
SDK AGC Core / API（@hw-agconnect/core-ohos、@hw-agconnect/api-ohos） 华为软件技术有限公司及其关联公司 用于初始化和调用 AGC 相关服务，为华为账号、应用基础服务等能力提供基础支持。 应用标识、项目配置、服务调用上下文、必要的设备和网络请求信息。 应用启动、初始化 AGC 服务或调用 AGC 能力时。 否 是 以 AppGallery Connect 和华为相关开发者服务说明为准。

外部服务 Bing 每日壁纸 Microsoft 获取每日壁纸图片和图片说明，用于首页壁纸展示。 网络请求信息、地区参数、壁纸元数据和图片文件。 用户开启每日壁纸或应用按设置刷新壁纸时。 是 是 以 Microsoft / Bing 公布的隐私声明和服务规则为准。
外部服务 内置搜索引擎：Bing、Google、DuckDuckGo、百度 Microsoft、Google、DuckDuckGo、百度等 按用户选择的搜索引擎发起搜索请求。 搜索关键词、访问时间、IP 地址、浏览器请求信息，以及搜索服务可能自行处理的 Cookie 或站点数据。 用户在地址栏或搜索框提交搜索时。 是 是 以用户选择的搜索引擎服务方隐私政策和 Cookie 政策为准。
外部服务 Aira 系统翻译 Aira 及其云服务提供方；可能使用腾讯云机器翻译或其他必要第三方机器翻译服务处理页面文字 为 Aira Pro 用户提供网页翻译能力。 待翻译文本、源语言、目标语言、翻译结果、必要的服务调用参数。 用户主动点击网页翻译或启用相关翻译操作时。 是 是 以 Aira 隐私声明、实际使用的机器翻译服务及相关云服务规则为准。
外部服务模板 第三方翻译服务模板：DeepL、Google Cloud Translation、腾讯云机器翻译、百度翻译、Microsoft Translator、阿里云机器翻译、火山引擎机器翻译、有道智云翻译 对应翻译服务提供方 用户自行配置 API Key、密钥或区域后，向对应翻译服务发起翻译请求。 待翻译文本、源语言、目标语言、API Key 或签名所需参数、翻译结果、请求日志等由对应服务方处理的信息。 用户选择并配置对应翻译服务后主动使用翻译功能时。 是 是 以用户选择的翻译服务提供方隐私政策、数据安全说明和开发者服务条款为准。
外部服务预设 WebDAV 预设服务商：坚果云、pCloud、GMX MediaCenter、kDrive、Koofr 对应 WebDAV 服务提供方 便于用户选择 WebDAV 服务地址，用于书签同步。 WebDAV 地址、用户名、密码或授权信息、书签和文件夹数据、同步文件、更新时间、同步状态等。 用户选择预设服务商、填写账号信息并开启 WebDAV 同步时。 是 是 以用户选择的 WebDAV 服务提供方隐私政策和服务规则为准。
4. 用户自定义第三方服务
类型 名称 提供方 使用目的 处理的信息 触发场景 是否用户主动触发 数据是否传出本应用 隐私政策或说明
用户自定义服务 用户自定义 WebDAV 服务 用户自行选择的 WebDAV 服务提供方 同步书签数据。 WebDAV 地址、用户名、密码或授权信息、书签 URL、标题、文件夹、排序、删除记录、同步状态和同步文件。 用户填写 WebDAV 信息并开启同步、手动同步或自动同步时。 是 是 Aira 不控制用户自定义 WebDAV 服务的数据处理行为，请以对应服务方规则为准。
用户自定义服务 用户自定义 HTTP 翻译接口 用户自行配置的接口服务提供方 按用户配置请求翻译接口。 待翻译文本、源语言、目标语言、请求头、请求体、认证参数和接口返回结果。 用户配置自定义接口并主动使用翻译功能时。 是 是 Aira 不控制用户自定义接口的数据处理行为，请仅配置可信接口。
用户自定义服务 广告拦截规则订阅地址 用户自行选择的规则源提供方 下载并更新广告拦截规则。 规则订阅 URL、网络请求信息、规则文件内容、更新时间和更新结果。 用户添加远程规则源、手动更新或应用按设置更新规则时。 是 是 Aira 不控制第三方规则源内容及其数据处理行为，请使用可信规则源。
用户自定义服务 用户脚本及脚本发起的第三方请求 用户脚本作者、脚本依赖服务或脚本请求的第三方服务 按用户安装的脚本逻辑增强或修改网页。 脚本可读取或修改的网页内容、页面 URL、表单内容、脚本配置、脚本发起的网络请求数据等，具体取决于脚本行为。 用户安装并启用脚本，且脚本匹配当前网页运行时。 是 可能 用户脚本由用户自行选择和安装，请仅安装可信来源脚本。
用户自定义服务 自定义搜索引擎 用户自行配置的搜索服务提供方 按用户配置的搜索 URL 发起搜索请求。 搜索关键词、搜索 URL、网络请求信息，以及对应搜索服务自行处理的数据。 用户将自定义搜索引擎设为可用搜索方式并提交搜索时。 是 是 Aira 不控制自定义搜索服务的数据处理行为，请以对应服务方规则为准。
用户自定义服务 自定义主页 / 第三方 HTML 主页 用户自行选择或导入的主页内容提供方 显示用户自定义的浏览器主页。 主页内容、主页中自行发起的网络请求、主页脚本可处理的数据，具体取决于用户导入的主页内容。 用户启用自定义主页并打开主页时。 是 可能 自定义主页由用户自行选择，请仅使用可信来源内容。
5. 用户主动访问的网站或网页服务

Aira 作为浏览器类应用，用户可以主动访问任意网页、网站及其关联服务。用户访问网页时，目标网站可能根据其自身隐私政策、Cookie 政策或服务规则收集和处理 IP 地址、Cookie、设备信息、网页表单内容、登录状态、浏览行为、支付或交易信息等。

Aira 不代表目标网站处理数据，也不对第三方网页内容、商品服务、交易结果、信息真实性或安全性作出保证。请您在访问、登录、提交表单、下载文件或进行交易前，关注目标网站自身的隐私政策和服务规则。
