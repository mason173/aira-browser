统一设计原则

  • 透明区域不承载隐藏按钮或不可见功能。
  • 2vp 白色外框持续标识卡片边界。
  • 白色品牌、图标与文字保证功能可识别。
  • 全部不透明视觉元素合计不低于卡片面积的 10%。

申请理由

Aira 是浏览器应用，1×2、2×2、2×4 桌面卡片分别提供搜索入口，以及书签、历史、下载和设置等常用功能入口。为减少大面积实色背板对用户桌面壁纸的遮挡，并使卡片更自然地融入 HarmonyOS 桌面视觉体系，现申请“背板透明卡片”能力。

透明能力仅用于背板视觉呈现，不新增或改变任何交互。所有可点击功能均通过持续可见的白色描边、图标或文字明确标识，不透明内容占比不低于 10%；透明区域不承载隐藏操作，不模拟系统组件，也不展示、读取或上传用户的书签、历史记录、下载内容等个人数据。
