# Bookmark Sync Sources Are Single-Select In Settings

Superseded by ADRs 0025, 0026, and 0027. The primary remains single-select, but optional backup sources now coexist with it, and Personalization Sync is free and shares the provider topology.

Accepted: settings UI will present Huawei Space Sync, WebDAV, and Aira Cloud Sync as a single-select Primary Sync Source list for bookmark sync, not as three independent switches. Huawei Space Sync and WebDAV are free bookmark sources, Aira Cloud Sync is Pro-only, Huawei Space Sync is gated by readiness, and Personalization Sync remains in a separate Pro-only area.
