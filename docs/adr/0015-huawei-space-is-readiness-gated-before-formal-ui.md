# Huawei Space Is Readiness-Gated Before Formal UI

Accepted: Huawei Space Sync will not appear as a normal user-selectable primary sync source in formal settings UI until cloud-side deployment, schema/version compatibility, account/platform prerequisites, and client capability checks pass. Development or diagnostic entry points may exist earlier, but exposing the provider prematurely in normal settings would make cloud-side setup failures look like broken Aira sync.
