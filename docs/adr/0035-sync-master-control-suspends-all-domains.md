# Sync Master Control Suspends All Domains

Accepted: the user-facing Sync Experience has one master on/off control even though bookmark and personalization remain independently stored Sync Domains. Because whole-experience suspension is a high-impact action, the master control is exposed only in Advanced Settings; the main Sync page uses a non-interactive cloud-sync header instead of a master/status card. Turning the master control off creates a non-destructive Sync Experience Suspension across every previously enabled domain: it stops automatic reads and writes but retains the Sync Goal, provider topology and credentials, local and remote data, and per-item content selections; turning it back on resumes those domains through their safe resume rules. Bookmarks and every Common Settings item are independent controls on the main Sync page. There is no user-facing Common Settings aggregate switch: the hidden Personalization Sync Domain starts when the first Common Settings item is enabled and pauses when the last item is disabled. Disabling any lower-level content switch never creates whole-experience suspension and therefore never turns the master control off; if every item is paused, the configured Sync Experience remains on and asks the user to select content. This keeps internal domain mechanics out of the novice flow while preserving granular control.
