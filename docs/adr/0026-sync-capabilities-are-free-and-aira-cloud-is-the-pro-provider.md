# Sync Capabilities Are Free And Aira Cloud Is The Pro Provider

Accepted: automatic synchronization, bookmark synchronization, and Personalization Sync are free product capabilities. Huawei Space Sync and WebDAV may provide either Sync Domain without Pro because the user supplies the storage resource; Aira Cloud Sync requires Pro whenever it is selected as a primary or backup source because Aira supplies the hosted infrastructure and browser-extension-based cross-system bookmark synchronization. The extension does not consume Aira personalization data, which remains useful only to compatible Aira clients. If Pro expires, Aira Cloud becomes unavailable in its existing role: as primary it pauses cloud/extension read-write and leaves local changes pending; as backup it stops backup writes while other synchronization continues. Aira does not switch providers, clear configuration, or delete remote data merely because entitlement expired. Renewal restores eligibility for the retained role. Aira Cloud sync data has no subscription-expiry retention deadline: it remains recoverable, including if moved to internal archival storage, until the user explicitly deletes Aira Cloud sync data or closes the account. This supersedes the Pro-only personalization and bookmark-only Huawei Space decisions in ADRs 0017 and 0018 without collapsing bookmark and personalization data into one Sync Domain.
