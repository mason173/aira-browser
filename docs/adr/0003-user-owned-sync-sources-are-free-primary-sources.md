# User-Owned Sync Sources Are Free Primary Sources

Accepted: Huawei Space Sync and WebDAV can both be selected as the primary sync source by free users because their storage resources are supplied by the user, not by Aira. Aira Cloud Sync remains the Pro-only primary sync source because it uses Aira's self-hosted backend resources; backup copies to non-primary providers are a separate advanced behavior, not the entitlement rule for choosing the primary source.
