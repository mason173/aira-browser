# Huawei Space Diagnostics Are Redacted

Accepted: Huawei Space Sync logs, diagnostics, and error reporting must not include bookmark URLs, titles, folder names, search terms, page content, tokens, cookies, raw auth material, raw sync payloads, or full snapshots. Diagnostics may include redacted metadata such as provider state, error codes, schema version, source id, counts, generation numbers, timings, and failure categories so Aira can troubleshoot without exposing user bookmark content.
