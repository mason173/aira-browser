# Huawei Space Does Not Auto-Migrate Existing Users

Accepted: shipping Huawei Space Sync must not automatically move existing users from Aira Cloud Sync, WebDAV, or local-only bookmark state. Switching to Huawei Space Sync requires an explicit user action and the shared primary-source switching flow so Aira does not silently alter a user's chosen bookmark authority, remote history, or multi-device conflict state.
