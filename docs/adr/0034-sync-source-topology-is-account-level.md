# Sync Source Topology Is Account-Level

Accepted: Primary and Backup Sync Source roles form one versioned account-level topology shared by compatible Aira devices and the Aira Cloud extension service. Provider metadata carries the topology identity/version, while credentials such as WebDAV passwords remain device-local. A new device adopts the topology found through the configured authority; if local and remote roles conflict, synchronization blocks instead of allowing device-specific primaries or overwriting the newer topology. When a retained backup lacks credentials on one device, that device keeps the account-level role, marks the provider unavailable, and does not require it to participate in a primary switch; older backup metadata is reconciled on the next authorized write instead of overriding a newer topology. This prevents two devices from treating each other's primary as a write-only backup and creating mutually destructive split authority.
