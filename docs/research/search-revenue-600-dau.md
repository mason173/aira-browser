# 600 DAU 浏览器内置搜索收入估算

日期：2026-08-28\
调研对象：浏览器把地址栏/搜索框查询导向合作搜索引擎后，浏览器厂商可能获得的搜索分成或固定费用。金额均为公开案例的量级参照，不是 Aira 可直接拿到的报价。

## 结论

公开资料没有百度、360、搜狗或其他搜索引擎面向小型第三方浏览器的统一“每次搜索”价目表。能负责任地给出的结论是：

- 没有签署分成/默认搜索合同前，收入按 **¥0/天** 预算；把搜索 URL 内置进浏览器本身不会自动产生收入。
- 用 Opera 和 Mozilla 的公开账目做用户规模类比，600 DAU 对应的浏览器方搜索收入大致是 **几美元到约 20 美元/天** 的量级，即在假设汇率 ¥7.2/USD 下约 **¥20--¥150/天**。这是乐观的“同等商业化能力”参照，不是百度或 360 的承诺。
- Aira 的用户主要在中国、规模远小于 Opera/Firefox，搜索意图、广告点击率、地区单价和合同分成比例都可能更低。拿到书面条款和一段真实试点数据前，内部现金预算可暂按 **¥0--¥50/天（管理假设）**，并把更高值视为待验证上限。

## 可核实的一手案例

### Opera Limited（2024 年 Form 20-F）

Opera 的年报直接说明：用户通过浏览器内置的地址栏/搜索栏使用 Google、Yandex 等合作搜索引擎进行“qualified search”时，Opera 按合同获得合作方搜索广告收入的一部分；如果用户点击搜索结果页广告，才会触发广告分成，另有可能存在浏览器定制/集成固定或变量费用。[Opera 2024 Form 20-F，Note 3 / Search](https://www.sec.gov/Archives/edgar/data/1737450/000095017025052668/opra-20241231.htm)。

年报披露的搜索收入（美元）为：2022 年 140.162M、2023 年 162.168M、2024 年 186.273M。2024 年各季度平均 MAU 为 303.6M、298.5M、296.0M、295.5M，季度平均约 298.4M；年报将 MAU 定义为每月最后一天向前 30 天内活跃用户的平均数。

由此得到一个可复算的 Opera 参照：

```text
186.273M / 298.4M = $0.624 / MAU·年
$0.624 / 365 = $0.00171 / MAU·日
```

这只是 Opera 已经谈好合同、且用户结构偏向高 ARPU 市场后的已确认收入，不代表合作方广告总收入，也不代表 Aira 能拿到相同比例。

### Mozilla Foundation（2023 审计财务报表）

Mozilla 的审计报表把 royalties 定义为：Firefox 把客户搜索引擎设为默认或可选状态，Mozilla 通常按客户搜索引擎产生收入的某个百分比收取 royalties。[Mozilla 2023 audited financial statements，p.3、p.14](https://assets.mozilla.net/annualreport/2024/mozilla-fdn-2023-fs-final-short-1209.pdf)。

报表披露 royalties：2023 年 $494.874M，2022 年 $510.389M；2023 年总收入 $653.012M。报表还指出，2023 年约 85% 的合同客户收入来自同一客户，但没有在报表中点名该客户，因此不能把全部 royalties 无证据地标成“Google 付款”。

Firefox Public Data Report 的官方数据接口说明 MAU 是过去 28 天活跃的 Desktop 和 Mobile 客户数；2023-08-21 的 Worldwide MAU 为 203,139,456。[数据集说明](https://data.firefox.com/datasets/desktop/user-activity/index.json)、[MAU 数据](https://data.firefox.com/datasets/desktop/user-activity/Worldwide/MAU/index.json)。用该日期仅作数量级对照：

```text
$494.874M / 203.139M = $2.436 / MAU·年
$2.436 / 365 = $0.00667 / MAU·日
```

Mozilla 的参照值明显高于 Opera，原因可能包括合作条款、搜索广告点击、地区组合和 MAU 口径不同；它应被当作高位案例，而不是普遍单价。

## 把案例换算到 600 DAU

DAU 不是 MAU。缺少 Aira 的 DAU/MAU 留存比时，先用 20%--40% 做敏感性分析：

```text
MAU = DAU / (DAU/MAU)
600 DAU -> 1,500--3,000 MAU
```

使用上面的每 MAU·日参照，得到浏览器方收入的“等效值”：

| 参照 | 600 DAU、DAU/MAU=40% | 600 DAU、DAU/MAU=20% |
|---|---:|---:|
| Opera 2024 搜索收入口径 | $2.57/天（约 ¥18） | $5.13/天（约 ¥37） |
| Mozilla 2023 royalties 口径 | $10.01/天（约 ¥72） | $20.02/天（约 ¥144） |

汇率 ¥7.2/USD 仅为预算换算假设，未使用实时汇率。上表合并后的可沟通区间约为 **$3--$20/天（¥20--¥150/天）**；它反映的是“如果 Aira 的商业化效率接近已规模化浏览器”的数量级，而不是报价区间。

### 转换成“每次搜索需要多少钱”

若暂以每个 DAU 每天 3 次搜索，查询意图约为 1,800 次/天：

- Opera 等效值要求每个查询贡献约 $0.0014--$0.0029（约 ¥0.01--¥0.02）；
- Mozilla 等效值要求每个查询贡献约 $0.0056--$0.0111（约 ¥0.04--¥0.08）。

这些是由公开总账反推的有效收入，不是任何平台公布的 CPC/CPM 或结算单价。如果只有一半查询被认定为“有效用户/qualified search”，所需有效查询单价还要约翻倍。

## 国内平台公开规则能确认什么

### 百度移动合作平台

百度公开的[结算规则](https://mcp.baidu.com/front/text/?id=238&platform=4)写明“按照调起的有效用户付费结算”，按月依据百度平台账单确认上月结算数并开票。页面没有公开每个有效用户、搜索或点击的人民币单价，也没有给出第三方浏览器的固定保底。

因此百度报价必须向渠道经理索取书面定义：有效事件到底是调起搜索、搜索结果页展示、广告点击还是去重用户；不同地区/设备是否不同价；无效流量如何扣除；是否有最低结算门槛和最低保证。

### 360 渠道推广系统

360 官方渠道系统首页的公开脚本说明该系统支持“付费推广、换量推广和 360 搜索分成三种合作形式”，并把搜索分成描述为给网站提供移动搜索功能、让合作伙伴获得搜索分成。[360 渠道推广系统](https://channel.360.cn/)。

同一官方系统的换量规则还写明“1 积分 = 0.01 元”，WAP 产品的有效量是“有效搜索量”。这是换量/积分对账规则，不应误读成现金搜索分成的固定单价；现金分成仍以具体合同和后台账单为准。

## 预算与验证建议

1. **合同缺失时按 ¥0/天**。默认把搜索框指向百度、360 等公开网页，不会自动产生可结算收入。
2. 向每家平台索取“有效事件定义、单价或收入分成百分比、地区系数、无效流量规则、最低保证、结算周期”的书面条款；不要用网上的站长教程或过时联盟截图替代合同。
3. 先做 4--8 周非独家灰度，记录聚合指标：DAU、查询次数、有效事件、广告点击（若允许）、按引擎/地区的结算金额。不要为估算收入长期保存原始搜索词。
4. 用真实试点反推：

```text
日收入 = 有效事件数 × 合同单价 + 合同固定费（日摊） - 无效流量扣款
```

   若平台按收入分成结算，则将合同单价替换为“合作方确认的可分成广告收入 × Aira 分成比例”。

## 口径和时效边界

- Opera 年报中的 search revenue 是 Opera 按合同确认的收入，包含搜索广告分成及部分搜索集成费用；不是搜索引擎广告主支付总额。
- Mozilla royalties 由多个搜索客户构成，报表未按客户拆分，且 Firefox MAU 数据与财务年度并非同一时点，不能据此反推出百度/Google 的单次搜索价格。
- Opera、Mozilla 的用户主要是全球桌面/移动浏览器用户；Aira 的 HarmonyOS、中国地区用户组合可能使实际 ARPU 更低。
- 微软官方已宣布 Bing Search APIs 于 2025-08-11 退役，现有实例会被停用且不再接受新注册；API 价格不应被当作浏览器搜索分成依据。[Microsoft Lifecycle 公告](https://learn.microsoft.com/en-us/lifecycle/announcements/bing-search-api-retirement)。
