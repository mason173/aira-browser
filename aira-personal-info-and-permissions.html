Aira个人信息收集与权限使用清单

更新日期：2026年5月27日

1. 说明

本清单依据 Aira 当前版本已实现并对外提供的功能编写，用于以清单形式说明我们在不同功能场景下可能处理的个人信息类型、处理目的、处理方式，以及为实现相关功能可能调用的系统权限或系统能力。

本清单是《Aira隐私声明》的补充说明，不构成对《Aira隐私声明》的替代。涉及个人信息处理规则、保存期限、信息存储地点、第三方共享或委托处理、用户权利行使方式及联系我们等内容，请以《Aira隐私声明》为准。

Aira 是浏览器类应用。除 Aira 自身功能外，您主动访问的网站、登录的网页、提交的表单、下载的文件、安装的用户脚本、配置的 WebDAV、翻译接口或广告规则源，可能由对应第三方按照其自身规则处理数据。请您同时关注目标网站或第三方服务的隐私政策。

如 Aira 的功能、第三方 SDK、第三方服务或系统权限调用发生变化，我们将根据实际情况更新本清单，并在适用法律法规要求的范围内通过适当方式提示您。

2. 个人信息收集与使用清单
功能场景 收集或处理的信息 使用目的 处理方式 是否必要 是否上传服务器或传出本应用 保存位置或期限 用户控制方式
网页浏览与标签页 网页 URL、网页标题、当前标签页、导航历史、页面加载状态、站点来源、页面恢复状态、最近关闭标签页等。 加载网页、恢复标签页、管理浏览会话和提供浏览器基础功能。 主要在本机处理；访问网页时会向目标网站发送网络请求。 基础浏览功能必要。 访问网页时会传出至用户访问的网站；Aira 不代表目标网站处理数据。 本机保存，按用户设置和清理操作保留；私密会话按私密数据边界处理。 可关闭标签页、清理历史/站点数据、使用私密浏览或卸载应用。

书签、文件夹与主页快捷方式 书签 URL、标题、文件夹、排序、创建/更新时间、主页快捷方式、图标信息。 保存和管理书签、首页快捷入口、导入导出和同步。 本机处理和保存；用户开启同步时按所选同步方式上传。 书签和快捷方式功能必要。 默认不上传；开启书签云同步或 WebDAV 同步后会上传至对应服务。 本机保存；同步数据按华为云服务或用户选择的 WebDAV 服务规则保存。 可编辑、删除、导入导出，或关闭同步、退出华为账号、删除 WebDAV 配置。
华为账号登录与账号资料展示 华为账号标识、AGC 用户标识、昵称、头像、登录状态、授权结果、必要的鉴权信息。 识别登录用户、展示账号信息、支持书签云同步、会员权益识别和邀请码能力。 通过华为账号服务和 AGC 认证服务处理；Aira 在本机保存必要登录状态和展示信息。 仅使用华为账号、云同步、会员权益或邀请码相关功能时必要。 会传出至华为账号、AGC 认证和相关云服务。 本机保存登录状态和资料缓存；云端按华为相关服务规则保存。 可退出华为账号、关闭云同步，或通过隐私政策载明方式联系我们处理相关请求。
书签云同步 华为账号标识、书签 URL、标题、文件夹、排序、删除记录、同步版本、同步时间、冲突状态等。 在多设备之间同步书签数据。 本机生成同步快照，并通过华为 Cloud DB 等云能力读写同步数据。 开启书签云同步时必要。 会上传至华为云服务。 本机和云端保存；云端保存期限以实现同步所需和相关服务规则为准。 可关闭书签云同步、退出账号、清理本机数据或联系我们处理云端相关请求。
WebDAV 同步 WebDAV 地址、用户名、密码或授权信息、书签 URL、标题、文件夹、排序、同步文件、同步锁、同步时间和冲突状态。 使用用户自行配置的 WebDAV 服务同步书签。 本机保存配置，并按用户操作向 WebDAV 服务上传、下载和合并同步文件。 开启 WebDAV 同步时必要。 会传出至用户选择的 WebDAV 服务。 配置保存在本机；同步文件保存在用户选择的 WebDAV 服务中。 可关闭 WebDAV 同步、删除配置、清除同步记录或在 WebDAV 服务端删除同步文件。
Aira Pro 会员、订阅、恢复购买和邀请码 华为账号标识、会员档位、会员有效期、订阅状态、商品 ID、购买结果、邀请码、邀请码额度、授权来源和必要的云端授权记录。 开通、校验、恢复和展示 Aira Pro / Aira Club 等会员权益。 通过华为应用内支付、AGC / Cloud DB 等能力处理；本机保存必要会员状态缓存。 使用会员、订阅、恢复购买或邀请码功能时必要。 会传出至华为应用内支付、AGC 和相关云服务。 本机保存状态缓存；云端授权记录按实现会员权益所需保存。 可管理订阅、恢复购买、退出账号，或通过联系方式申请核查会员状态。
搜索和搜索建议 搜索关键词、当前搜索引擎、搜索建议设置、本地历史/书签/快捷方式匹配结果；开启远程建议时会处理搜索词。 提交搜索、展示本地或远程搜索建议。 本地建议在本机处理；远程搜索或远程建议会按用户选择的搜索引擎发起请求。 搜索功能必要；远程搜索建议为可选。 提交搜索或开启远程建议时会传出至用户选择的搜索引擎。 搜索设置保存在本机；第三方搜索引擎按其规则处理请求。 可关闭远程搜索建议、切换搜索引擎、清理历史记录。
网页翻译 待翻译文本、源语言、目标语言、翻译服务配置、API Key 或签名参数、翻译结果和翻译缓存。 提供网页翻译、双语显示或译文替换。 根据用户选择的翻译服务在本机处理或向 Aira 系统翻译、用户自定义接口或第三方翻译服务发送请求。 使用翻译功能时必要。 会根据所选翻译服务传出至对应服务方；不开启翻译则不处理。 翻译设置和必要缓存保存在本机；第三方服务按其规则处理。 可关闭翻译、切换或删除翻译服务配置、清理相关配置。
下载管理 下载 URL、文件名、文件类型、文件大小、保存路径、下载进度、任务状态、失败原因和下载记录。 下载文件、展示下载进度、打开文件或文件位置、管理下载记录。 本机处理和保存；下载时向文件来源地址发起网络请求。 下载功能必要。 下载请求会传出至文件来源站点；下载记录通常不上传。 文件保存在用户选择或默认下载位置；记录保存在本机，可由用户删除。 可删除下载记录、删除文件、修改下载保存策略或选择保存位置。
离线网页保存 网页 URL、标题、页面 HTML、页面资源、保存时间、预览图、离线页面文件和占用空间信息。 离线保存、管理和查看网页内容。 本机处理和保存页面快照及相关文件。 使用离线网页保存功能时必要。 通常不上传；页面资源下载会访问原网页或资源地址。 保存在本机应用目录，直到用户删除或清理。 可在离线页面管理中删除、导出或清理。
广告拦截和隐藏规则 规则源地址、规则文件内容、本地导入文件、站点例外、隐藏规则、更新时间、规则解析结果。 拦截广告资源、隐藏网页元素、管理规则源。 本机保存和应用规则；远程规则源会按用户配置下载。 使用广告拦截、规则源或隐藏规则时必要。 远程规则更新时会向规则源发起请求；规则配置通常不上传。 保存在本机，直到用户删除规则、清空或卸载应用。 可关闭广告拦截、删除规则源、清理站点例外和隐藏规则。
用户脚本 脚本源码、脚本名称、匹配规则、下载地址、安装来源、权限声明、资源依赖、脚本存储值、启用状态和更新时间。 安装、运行和管理用户脚本。 本机保存和运行；脚本可按其代码逻辑读取或修改网页内容并发起网络请求。 使用用户脚本功能时必要。 Aira 默认本机处理；脚本自身可能向第三方发送数据，取决于脚本行为。 脚本和脚本值保存在本机，直到用户删除脚本或清理数据。 可禁用、删除脚本，清理脚本数据，并仅安装可信来源脚本。
站点权限与站点数据控制 站点来源、摄像头/麦克风/位置/传感器权限规则、第三方 Cookie 策略、站点数据清理选项。 管理网页权限请求、保存站点级允许/拒绝规则和清理站点数据。 本机处理和保存权限规则；网页实际数据由 ArkWeb / 目标网站按系统能力处理。 站点权限管理功能必要。 权限规则通常不上传；网页访问目标网站时会发生外部数据交互。 保存在本机；私密会话按私密数据边界处理。 可在站点信息、设置或清理页面修改、重置、删除站点权限和站点数据。
每日壁纸、主题和外观 壁纸设置、Bing 壁纸市场参数、壁纸图片、图片说明、主题色、深浅色设置、首页布局设置。 展示首页壁纸、主题色和外观配置。 本机保存设置；开启 Bing 每日壁纸时会请求 Bing 壁纸接口并缓存图片。 外观设置必要；Bing 每日壁纸为可选。 开启 Bing 每日壁纸时会传出网络请求至 Bing。 设置和缓存图片保存在本机，直到用户更改或清理。 可关闭每日壁纸、切换壁纸来源、修改主题或清理缓存。
本地头像 用户从系统图片选择器选择的图片 URI、头像图片文件。 用于本机账号卡片或本地头像展示。 通过系统图片选择器由用户选择单张图片，Aira 将选中图片复制到本机应用目录。 仅设置本地头像时必要。 不上传至 Aira 服务器；图片选择器和系统相册能力由系统提供。 头像文件保存在本机应用目录，直到用户替换、删除或清理应用数据。 可更换头像、退出账号或清理应用数据。
密码等敏感页面保护 密码设置状态、私密窗口保护状态；Aira 不在该清单范围内承诺收集网页密码内容。 保护密码相关页面，防止截屏或录屏，提升敏感页面安全性。 本机处理，调用系统隐私窗口能力。 使用密码或敏感页面保护时必要。 通常不上传。 设置保存在本机。 可在设置中管理密码相关能力和系统授权。
私密模式锁定 私密模式是否锁定、解锁状态、系统身份认证结果；Aira 不获取或保存指纹、面容等生物特征原始信息。 在进入私密标签页或应用回到前台时保护私密浏览内容。 调用系统生物识别/身份认证能力，仅接收认证成功、取消或失败结果。 启用私密模式锁定时必要。 认证由系统处理，Aira 不上传生物特征数据。 锁定状态保存在本机；生物特征由系统管理。 可关闭私密模式锁定或在系统设置中管理生物识别。
原生视频接管和后台播放 当前视频 URL、播放状态、标题或页面信息、后台播放状态。 接管网页视频播放、支持后台播放和媒体控制。 本机处理播放状态，并调用系统媒体、音频会话和后台运行能力。 使用视频接管或后台播放时必要。 视频资源请求会访问对应网站或资源地址；播放状态通常不上传。 临时处理或保存在本机状态中，按功能退出或清理。 可关闭相关功能、停止播放或退出页面。
文件导入、导出、分享和复制 用户选择的文件 URI、导入文件内容、导出文件内容、分享文本、复制到剪贴板的链接或文本。 导入书签/历史/脚本/规则/主页文件，导出历史、离线页面或调试文件，分享或复制链接。 通过系统文件选择器、系统分享或系统剪贴板处理；Aira 只处理用户选择或操作的内容。 使用相关导入、导出、分享或复制功能时必要。 分享时会传出至用户选择的目标应用；复制会写入系统剪贴板；导入导出文件由用户选择位置。 导入内容按对应功能保存在本机；导出文件由用户选择保存位置；剪贴板由系统管理。 可取消选择、删除导入数据、清理剪贴板或删除导出文件。
网页文件选择 用户通过网页文件选择器选取的文件 URI 和文件内容。 满足网页上传文件或保存文件的需求。 通过系统文件选择器选择文件，并按网页请求提供给当前网页。 仅网页请求且用户选择文件时必要。 可能上传至当前网页或网站，具体取决于网页行为。 Aira 通常不长期保存网页上传文件；目标网站按其规则处理。 可拒绝网页文件选择请求，或不选择文件。
诊断和测试工具 应用运行事件、标签页状态、页面恢复状态、权限事件、下载事件、同步事件、错误信息、导出的诊断文件。 排查问题、验证浏览器能力和辅助开发测试。 本机记录、查看、导出或清理。 诊断功能必要；普通浏览不依赖导出。 通常不上传；用户主动导出或分享时会传出至用户选择的位置或应用。 按诊断保留策略保存在本机，用户可清理。 可通过相关测试工具、导出文件位置或本机保留策略查看、导出或清理。
3. 系统权限与系统能力调用清单
权限或系统能力 用途 调用场景 是否询问授权 不授权或关闭的影响 是否可关闭或控制
网络访问（ohos.permission.INTERNET） 加载网页内容、搜索、下载、同步、翻译、规则更新、壁纸刷新和会员订阅等联网功能。 打开网页、搜索、下载、同步、翻译、刷新 Bing 壁纸、购买或恢复会员时。 按系统规则授权。 无法正常访问网页或使用联网功能。 可通过系统网络、应用联网控制或关闭相关功能进行控制。
获取网络状态（ohos.permission.GET_NETWORK_INFO） 判断网络状态，辅助联网功能、错误提示和同步/下载等操作。 应用需要判断网络可用性或联网状态时。 按系统规则授权。 网络状态判断和提示可能不准确。 可通过系统权限或网络设置控制。
摄像头（ohos.permission.CAMERA） 网页请求拍照、扫码、视频通话或 getUserMedia 摄像头能力时提供摄像头访问。 仅当当前网页主动请求摄像头，并经用户确认和系统授权后。 是。 网页摄像头相关能力不可用。 可在站点权限和系统权限中允许、询问或拒绝。
麦克风（ohos.permission.MICROPHONE） 网页请求录音、语音通话或 getUserMedia 麦克风能力时提供麦克风访问。 仅当当前网页主动请求麦克风，并经用户确认和系统授权后。 是。 网页录音、语音通话等能力不可用。 可在站点权限和系统权限中允许、询问或拒绝。
位置 / 模糊位置（ohos.permission.LOCATION、ohos.permission.APPROXIMATELY_LOCATION） 在网页请求定位时，为当前网页提供定位能力。 仅当当前网页主动请求定位，并经用户确认和系统授权后。 是。 网页地图、附近服务、定位表单等能力可能不可用。 可在站点权限和系统权限中允许、询问或拒绝。
加速度传感器（ohos.permission.ACCELEROMETER） 在网页请求设备运动或方向数据时提供传感器能力。 仅当当前网页主动请求相关传感器能力，并经用户确认和系统授权后。 是。 网页中的运动、方向、体感交互等能力可能不可用。 可在站点权限和系统权限中允许、询问或拒绝。
振动（ohos.permission.VIBRATE） 提供浏览器交互中的触觉反馈。 例如长按、拖拽、选择等本机交互反馈。 按系统规则授权。 触觉反馈不可用，不影响主要功能。 可通过系统振动设置或应用设置控制。
隐私窗口（ohos.permission.PRIVACY_WINDOW） 在密码等敏感页面防止截屏和录屏。 进入密码或其他敏感页面时。 按系统规则授权。 敏感页面的截屏/录屏保护可能不可用。 可通过系统权限或相关设置控制。
生物识别 / 身份认证（ohos.permission.ACCESS_BIOMETRIC） 使用系统身份认证保护私密模式标签页。 进入私密标签页、从后台回到包含私密内容的应用时。 是。 无法使用系统身份认证解锁私密内容，或需要关闭相关保护。 可在系统生物识别设置和 Aira 私密模式相关设置中控制。
后台运行（ohos.permission.KEEP_BACKGROUND_RUNNING） 支持原生接管视频时后台播放，并在下载文件时保持后台传输。 用户使用后台播放或下载任务仍需继续运行时。 按系统规则授权。 后台播放或后台下载可能中断。 可通过系统权限、后台运行设置或停止相关任务控制。
